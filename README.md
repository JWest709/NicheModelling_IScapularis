

This repository contains the software implementation for our paper "Rapid Northward Expansion of the blacklegged tick, Ixodes scapularis, in Response to Climate Change" (Westcott, Boden, Savage, Doody, 2025). It contains a sample script to run through one sequence of environmental variables and the associated species distribution maps.

Additionally, this respository contains the filtered collection of Ixodes scapularis records used in this analysis, which were sourced from both iNaturalist and eTick. For the most current tick observation data, please consult the following websites:

Etick: https://etick.ca/

iNaturalist: https://www.inaturalist.org

For climate data used in the analysis, please see the following websites:

AdaptWest: https://adaptwest.databasin.org/pages/adaptwest-climatena/

CHELSA-Bioclim: https://chelsa-climate.org/bioclim/
